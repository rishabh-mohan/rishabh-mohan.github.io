# Rishabh Mohan's personal website

Open `index.html` in your browser to view the site. No installation or build step is required.

To serve it locally, run `node server.cjs` from this folder, then visit http://localhost:5959. Refresh your browser after editing files. Press Ctrl+C to stop the server.

- Drag a window's six-dot grip or press two slot numbers in sequence to swap windows. A different key cancels the first selection.
- Expand a window to see all six details, jump to a section, or try its demo.
- Shuffle steps through random swaps and rebuilds the ASCII border in a different theme. Refreshing restores the opening layout and forest theme.
- Edit projects and per-slot text in `projects.js`. The site uses plain HTML, CSS, and JavaScript.
